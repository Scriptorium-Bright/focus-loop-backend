# FocusLoop UX Reboot Requirements v2.0

이 패키지는 기존 FocusLoop 화면을 점진적으로 수정하는 문서가 아니다.

**1인칭 소형 보트 항해 경험을 중심으로 제품 UX를 처음부터 다시 설계하는 요구사항·기획·검증 패키지**다. 기존 코드와 화면은 참고 자료로만 사용하며, 새로운 경험 흐름과 상태 모델을 먼저 확정한 뒤 필요한 부분만 재사용한다.

## 새 제품의 한 문장 정의

> 사용자가 해야 할 일을 정하면 작은 배의 1인칭 시점으로 출항하고, 집중 중에는 조용한 바다를 바라보며 항해하며, 일시정지하면 15초 동안 가까운 쉼터 항구를 찾아 정박하고, 세션 종료 시 목적지에 도착해 항해일지를 남기는 Ambient Focus Product.

## 핵심 사용자 질문

1. 이 화면을 일부러 켜두고 싶은가?
2. 25~60분 켜둔 상태에서 편안하게 집중할 수 있는가?
3. 일시정지와 복귀가 실패가 아니라 자연스러운 항해 과정처럼 느껴지는가?
4. 세션 종료 후 실제로 한 구간을 지나왔다는 도착감이 있는가?
5. 스킨과 항해일지 때문에 다음에도 다시 켤 이유가 있는가?

## 이번 Reboot에서 새로 정의하는 핵심

- 1인칭 보트 시점
- 출항 전 정박 상태
- 2~4초 출항 의식
- 집중 중 1인칭 유영
- 일시정지 즉시 시간 중단
- 15초 주변 항구 탐색
- 휴식 항구 정박
- 휴식 타이머와 자유 휴식
- 재출항
- 목적지 도착
- 항해일지
- 스킨 시스템
- 빠른 집중 / 오늘의 계획 / 긴 여정
- 재사용과 수익화 구조
- Web / Native 상태 및 렌더링 요구사항
- 검증·QA·출시 Gate

## 중요한 구현 원칙

- 기존 화면을 그대로 고쳐 붙이지 않는다.
- 먼저 상태 모델과 화면 흐름을 새로 확정한다.
- 1인칭 시점은 멀미를 유발하지 않도록 움직임을 매우 제한한다.
- 일시정지는 버튼을 누른 즉시 적용한다. 15초 항구 탐색은 시각적 전환일 뿐이며 시간 정지를 지연시키지 않는다.
- 항구 탐색은 건너뛸 수 있다.
- 스킨은 단순 색상 변경이 아니라 장면·사운드·출항·항구·도착의 묶음이다.
- 항해일지는 생산성 점수표가 아니라 지나온 시간의 기록이다.
- Harbor 경영 게임, NPC, 코인, 스트릭 손실은 기본 범위에 포함하지 않는다.
