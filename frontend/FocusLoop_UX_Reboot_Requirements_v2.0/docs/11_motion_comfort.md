# 11. Motion & Comfort Requirements

## 1. 1인칭 멀미 방지

- 자유 카메라 없음
- 수평선 기울기 최소
- Roll ±0.35도 이하
- Zoom 없음
- 급격한 Acceleration 없음
- 흔들림 설정 가능
- Reduce Motion

## 2. 출항

2~4초, Ease Out.

## 3. 수면

- 큰 명암 흐름 10~20초
- 작은 하이라이트 5~12초
- 선수 Bob 8~16초
- 서로 다른 주기

## 4. 항구 탐색

- 360도 회전 금지
- Compass와 Parallax
- 후보 불빛
- 15초

## 5. 휴식

- 배 움직임 30~50%
- 파도 속도 감소
- 항구 불빛
- UI 안정

## 6. 도착

- 2~4초
- 움직임 감소
- 빛 강화
- Sheet 등장

## 7. 실제 검증

- 30fps 30초
- 25분 사용자 테스트
- Motion 민감 사용자
- 모바일 실기기
