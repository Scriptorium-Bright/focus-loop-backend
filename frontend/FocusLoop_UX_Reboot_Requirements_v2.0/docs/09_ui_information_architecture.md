# 09. Information Architecture & Navigation

## 1. 주요 탭

### Home

정박 상태, 작업 시작.

### Journeys

오늘의 계획과 긴 여정.

### Logbook

일간·주간·프로젝트 기록.

### Skins

환경 선택과 Preview.

Settings는 Header 또는 별도 화면.

## 7. 모바일 우선

- Bottom Navigation 3~4개
- Safe Area
- 320×568 지원
- Composer 핵심 CTA 항상 보임
- 목록만 Scroll

## 8. 데스크톱

- Scene을 넓게 유지
- Composer 최소 가독 크기
- 모바일 패널을 단순 확대하지 않음
- Sidebar는 옵션
